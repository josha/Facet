## Verification notes

- **Fusion LICENSE integrity.** `git log --oneline -- vendor/Fusion/LICENSE` returns exactly one
  commit (`6a4b59c`, the initial import). The file has never been modified. Its first three lines
  read `MIT License` / blank / `Copyright (c) 2024 Daniel P H Fox`.
- **Fusion local patches.** `vendor/Fusion/VENDOR.md` records the upstream as tag `v0.3-beta` with
  `src/` copied verbatim. Patches are mechanical: `require(Package.X)` → `require("../X")` string-require
  form across 54 files, plus one scheduler guard in `init.luau` (`doTaskImmediate` runs callbacks
  synchronously, because the upstream queue-and-yield variant kills Lune's main thread). No logic changed.
- **SCOWL notice location.** `examples/gallery/examples/words/PROVENANCE.md` is 16,073 bytes / 341 lines.
  The "Required notices" section starts at line 85; the verbatim `Copyright` block is lines 92–341.
  Copyright lines confirmed present at 93, 96, 186 (WordNet/Princeton), 265 (UKACD/Beresford),
  287 (VarCon/Atkinson), 297 (Titze), 309 (Kuenning).
- **The UKACD clause is the strict one.** It requires that "the copyright notice must be prominently
  displayed and the text of this document must be included verbatim." Today that is satisfied only
  because the whole SCOWL `Copyright` file is reproduced. **Never truncate or summarise that block.**
- **No font, no audio.** Searched all refs for `.ttf`, `.otf`, `.woff`, `.woff2`, `.mp3`, `.wav`,
  `.ogg`: zero blobs. The 673 binary blobs in history are 530 `.rbxl`, 135 `.png`, 4 `.jpeg`,
  3 `.mov`, 1 `.mp4`.
