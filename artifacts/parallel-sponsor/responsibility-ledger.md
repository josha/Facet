# Parallel Sponsor (Step 6) — declarative-responsibility ownership ledger

**Date opened:** 2026-07-30 · **Stage:** `parallel-sponsor`
**Rule** (`LUAUUI_SPONSOR_PARALLEL.md` § Declarative responsibility test): every
custom helper, direct Roblox UI/input access, device/layout branch, or legacy
workaround the new presenter appears to need gets a row BEFORE it is written.
A framework-owned need is implemented in LuauUI with public API + tests + docs
+ live proof, then consumed here — never worked around screen-side. The
presenter must contain NO: manual GUI Instance construction, platform-name
branches, parallel focus/input/layout/control machinery, imperative responsive
geometry, or tweens around the motion authority.

**Dispositions:** `FRAMEWORK` (public LuauUI API closes it) ·
`GAME-DECLARATIVE` (semantic state/content/blueprints, fine as-is) ·
`GAME-BOUNDARY` (named engine-only glue at an explicitly game-owned edge) ·
`ESCALATE` (decision packet; not hidden behind a workaround).
