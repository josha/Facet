# rich-skinning-v2 acceptance ledger

**Gate:** `rich-skinning-v2` · **Created:** 2026-07-25 ·
**Contract:** `docs/plans/agent-execution-contract.md` §2 · **Matrix:** `docs/plans/studio-device-verification.md`
**Governing doc:** `docs/plans/rich-skinning-v2.md` (the charter).

This stage builds ON the shipped Step 3.5 contract (ADR-0019: `LuauUI.themes`, the frozen
`ThemeSnapshot`, `theme_controller`, chrome slots + tag families, the chrome text lift,
`chrome.focus`) — it consumes that contract and never reopens it. Stage-start suite floor:
**1336** (green, 2026-07-25). `LuauUI.VERSION = 0.6.0` at stage start.

Status values are the contract's honest states: `PASS_AUTOMATED`, `PASS_PHYSICAL`, `PASS_HUMAN`,
`FAIL_PRODUCT`, `FAIL_ENVIRONMENT`, `PENDING` (automated work not yet performed),
`PENDING_PHYSICAL`, `PENDING_HUMAN`. A row cannot pass through a different, easier row; evidence
levels are the contract §3 ladder. Every `PASS_*` must cite an artifact produced by a tool run
in the session that set it. **All rows start PENDING; a status changes only when its artifact
exists.**

Stage acceptance centerpiece: *a heavily stylized game makes every visible part of the UI
artwork through public APIs alone — layered frames with corner ornaments and title plaques,
bars whose track AND fill are images clipped by value, per-state art swaps (not tints) at both
customization rungs, semantic icons, a pixel-art package rendered nearest-neighbor crisp, and
one view tree that re-skins itself between a glossy touch package and a compact pointer package
when the player docks — with mount/focus/scroll identity, accessibility floors, censused cost,
and flat themes still paying zero.* A capture without its paired geometry/state trace is
insufficient for every row below.
