# native-substrate acceptance ledger

**Gate:** `native-substrate` (roadmap Step 1) · **Created:** 2026-07-23 · **Contract:** `docs/plans/fable-execution-contract.md` §2
**Governing docs:** `docs/plans/roblox-native-audit-corrections.md` (wins on conflict) → `docs/plans/roblox-native-primitives.md`.

Status values are the contract's honest states: `PASS_AUTOMATED`, `PASS_PHYSICAL`, `PASS_HUMAN`,
`FAIL_PRODUCT`, `FAIL_ENVIRONMENT`, `PENDING` (automated work not yet performed),
`PENDING_PHYSICAL`, `PENDING_HUMAN`. A row cannot pass through a different, easier row;
evidence levels (E0–E5) are the contract §3 ladder. Every `PASS_*` must cite an artifact
produced by a tool run in the session that set it. **All rows start PENDING; a status changes
only when its artifact exists.**

  paired JSON (Studio `screen_capture` has no disk sink — recorded id + paired trace is the capture evidence).
