`syncTags` is ADDITIVE ONLY. Every facet-* classification tag ever applied to an
instance stays on it for the instance's whole life.

--- 3. THE LINE ---
src/client/screen_target.luau:566
    if string.sub(tag, 1, 5) == "facet-" and desired[tag] ~= true then
`string.sub(tag, 1, 5)` is "facet" (5 chars); "facet-" is 6. The comparison can
never be true, so the removal half of syncTags is dead code.

--- 4. WHEN IT BROKE ---
commit 36d1883 (2026-08-18, "the tags were the largest surviving old name, and the
guard could not see them", ADR-0038, tag rename luau-* -> facet-*), inside the
release-candidate-review window. Diff of that commit at this line:
-  if string.sub(tag, 1, 5) == "luau-" and desired[tag] ~= true then
+  if string.sub(tag, 1, 5) == "facet-" and desired[tag] ~= true then
"luau-" is 5 characters, so the sub length was correct before the rename and
wrong after it. The 395-occurrence sweep rewrote the literal and not the length.
