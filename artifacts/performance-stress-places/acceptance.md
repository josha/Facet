# Performance stress places — acceptance ledger (roadmap Step 9)

**Stage:** `performance-stress-places` (docs/plans/performance-stress-places.md)
**Written:** 2026-08-04, BEFORE implementation (execution contract §2).
**Gate:** `tools/gate.sh performance-stress-places` → `artifacts/performance-stress-places/gate.json`

Status vocabulary (contract §2): `PASS_AUTOMATED`, `PASS_PHYSICAL`, `PASS_HUMAN`,
`FAIL_PRODUCT`, `FAIL_ENVIRONMENT`, `PENDING_PHYSICAL`, `PENDING_HUMAN`. A row
cannot pass through a different, easier row. In particular: **no Lune number and
no Studio number closes a device row**, and the Studio device emulator proves
layout and operability only — never low-end performance.

## Baseline facts this ledger is written against (audited 2026-08-04, current source)

- `bench/perf_scenes.luau` carries 18 headless scenes driven by
  `bench/perf_runner.luau` through the `FakeTarget` adapter; `tools/lune/perf.luau`
  enforces `bench/perf_budgets.json` and already refuses to satisfy a device budget
  from a host row (`perf_runner.provenanceProblems`). **No engine is involved.**
- `examples/gallery/scenarios/runner.luau` is the existing Studio verification
  surface: `list/steps/step/report/reset/freezeEnv/setEnv` over
  `workspace.LuauUIScenarioAPI` BindableFunctions, with telemetry seams for frame
  work, instances, connections, memory, raw input, and paint watch.
- `examples/gallery/scenarios/perf_capture.luau` is the Step-4 production-shaped
  fixture: 200 logical rows, a text-only cell, one theme-swap step. It measures
  `presenter.refresh()` wall time — it is **not** a scroll workload, has no image
  or control in its row, no native reference, no ramp, no clean-capture mode, and
  no MicroProfiler scope.
- `tools/build_places.sh` emits nine `.rbxl` files from inline Rojo project JSON.
  There is **no checked-in project file** for a performance place and no place
  doctor check.
- **`src/` contains zero `debug.profilebegin` calls** (grepped). Every LuauUI phase
  is invisible to the MicroProfiler today; captures would show `$Script` only.
- `LuauUI.VERSION = "0.8.0"`; suite floor at stage start = **3319** passing.

## Decision packets

Recorded in `artifacts/performance-stress-places/decisions.md` as PLN-*:

- PLN-1 — one place vs two: whether a dormant native reference can be kept in the
  same place without affecting the LuauUI capture, decided from a measurement.
- PLN-2 — the MicroProfiler scope set: which phases are named, why the list is
  bounded, and what a scope deliberately does **not** split.
- PLN-3 — the capture-metadata schema and what makes a row inadmissible.
- PLN-4 — the optimization-loop outcomes, including negative and inconclusive
  attempts and why each was abandoned.
- PLN-5 — Instance recycling: the measured LuauUI-vs-native gap, and why it is
  escalated rather than attempted.
- PLN-6 — `UI.Text` draws embedded newlines and does not measure them: recorded and
  routed rather than fixed inside a performance stage.
- PLN-7 — the device-budget position while PL-P1/PL-P2 stay pending, and why PL-P3
  is a separate honest row rather than folded into PL-1.
