# Side-by-side captures

Each row pairs a capture of `main` with a capture of this branch at the same
viewport. Both sides are Studio playtests on a 1x display with the device
simulator off, so each image pixel is one viewport pixel.

- `main`: `origin/main` at `bc9a56a6`, `examples/showcase.project.json`, in a second Studio. See `main/manifest.json`.
- Branch: the gallery place in Studio `dacb4cb1` with the sources of this branch. See `pr/manifest.json`.
- Both sides show each demo as it first opens, with the default theme. The 844x390 captures use a mouse and keyboard client with a phone-shaped viewport, not phone emulation.
