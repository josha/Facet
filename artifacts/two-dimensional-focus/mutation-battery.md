# ADR-0030 mutation battery — 18 mutations, 17 red, 1 null

**Harness.** each mutation applied to a worktree at HEAD + only this change, then tests/_battery (505 cases: focus, focus_skip, focus_grid_axis, navigation_groups, traversal_order, keyboard_navigation, virtual_grid, virtual_grid_input, virtual_hgrid, table_input, rating, row_actions, examples_gallery) run to completion; reverted after

**Baseline.** 505 passed / 0 failed unmutated; the same source runs the FULL suite at 5421 passed / 0 failed

**Corroboration.** M1-M4 and M6 were also run against the FULL 5421-case suite (battery-fullsuite-M1-M5.log) and reddened the same named cases plus their downstream grid cases; the targeted runner is not hiding collateral damage (`battery-fullsuite-corroboration.log`, gitignored — the five runs are quoted below).

## The null result, named

> M8 (entry does not clamp into a ragged last line) reddened NOTHING. Not a coverage hole: the clamp it removed was redundant with nearestEligible's own math.clamp of its start index. The redundant clamp was DELETED rather than covered with a test that would only have re-proved nearestEligible. The ragged-entry behaviour it looked like it protected is still held by M6 and M7.

## Notes on the two mutations that taught something

**M3** did not merely fail — it *hung*. Dropping the clamp's own guard made the perpendicular walk non-terminating, so the suite never returned and named no case at all. A red that cannot say what it broke is a different kind of red, and the fix was structural: the loop is now bounded by the line count rather than by its exit conditions.

**M8** reddened nothing, and that is recorded rather than papered over. The clamp it removed was redundant with `nearestEligible`'s own clamp of its start index — the same clamp twice. It was **deleted**, not covered by a new test, because a test written to make M8 look covered would only have been re-proving `nearestEligible`. The ragged-entry behaviour it appeared to guard is still held by M6 and M7.

**M13** is the gate mutation and the one that matters most for everything this change did *not* touch: reading every 1-D group as a rectangle of one lane reddened 17 cases across `navigation_groups`, `focus` and the entry rules. That is what makes "every path is gated on `columns`" a checked claim rather than a described one.
