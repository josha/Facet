# Gallery parity audit

Baseline: `a8c8895673c0745506908b66dc89f8cead6b66f3`. Candidate: the shared `compose-ui-simplification` worktree on 2026-09-23. This is a bounded source comparison, not a live-rendering certification. Source, callback, authored-content and navigation differences were compared across the current scenario catalogue and shell. Existing test bodies were read. No tests, Studio operations or source changes were performed during this audit because benchmark timing had priority. Only this report was written after the first timing freeze ended.

The gallery is not at behavioral parity. Several replacement demos exercise a smaller task than their main counterparts. Successful construction and the current narrow workflow assertions do not close these gaps. Removed Facet owners, presenters, solvers, handles and resource facades are not themselves regressions; the lost player-visible tasks below are.

## Live checks still required

- The collection toolbar fixes its action row at 40 pixels, does not wrap, and reserves a fixed 144 pixels above content. Five text-sized buttons are present in every variant. Check 401×777 and compact landscape at default/largest preferred text size; inspect clipping, usable viewport and retained scroll. Main explicitly used wrapping, measured chrome for these pages.
- The shell reserves exactly 56 pixels, with a 40-pixel Demo picker and Settings button. Compare main's measured reservation under large text and every supported theme. Confirm both controls remain reachable and content starts below them.
- `preferred_transparency` now previews a local slider while the modal reads the actual native preference. Verify native `PreferredTransparency` at opaque/intermediate/default values; the slider is not evidence that native preference hot-swapping works.
- Retained pages containing sheets, alerts, menus, callouts, haptics and animated content require A→B→A checks. Visibility and owner lifetime are different; the proven world-marker issue should not be generalized into claims about other controls without checking them.
- For the unchanged task families below, use the real pointer/touch/keyboard/gamepad paths and main/candidate screenshots. Source preservation and direct signal firing do not prove focus, hit testing, text fit, skin geometry or gesture behavior.
