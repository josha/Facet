# Instructions for this project

Build the interface with plain Roblox Instances.

- Create the interface from Roblox classes such as `ScreenGui`, `Frame`, `TextLabel`, `TextButton`, `ImageButton`, `ScrollingFrame` and `TextBox`.
- Use the engine's native features for layout, style and input: `UIListLayout`, `UIGridLayout`, `UIFlexItem`, `UIPadding`, `UISizeConstraint`, `UIAspectRatioConstraint`, `UIScale`, `UICorner`, `UIStroke`, StyleSheets, `ScreenInsets`, `GuiService` selection, `ContextActionService` and `UserInputService`.
- Do not add a third-party UI framework or UI library.
- Studio MCP is the only tool. Edit the place directly in its Edit data model.
  Use Play, captures, input, and console output to check the game on the supplied
  devices and repair what you see.
