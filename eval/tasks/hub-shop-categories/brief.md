# Ticket: organize the hub shop

The racing team needs clearer shopping choices. Start from the completed racing hub. Keep its visual identity, economy, navigation, and all earlier behavior.

Add All, Motors, Boosts, Wheels, and Cosmetics category controls to Shop. All is selected each time Shop opens. A category shows only its items and keeps owned states and prices current.

For a purchase of at least 500 Coins or 100 Gems, first ask `Buy ITEM for PRICE CURRENCY?`. Show Confirm and Cancel. Cancel sends no purchase. Confirm sends one purchase. Smaller purchases work at once. If funds are too low, show the existing missing currency message without a confirmation. Use the existing catalog and purchase contract. Do not change the server or shared files.

| Element | Words |
| --- | --- |
| Categories | All, Motors, Boosts, Wheels, Cosmetics |
| Confirmation | Buy ITEM for PRICE CURRENCY? |
| Actions | Confirm, Cancel |

The categories and confirmation must work with touch and gamepad. Close or B returns one level and restores selection. The entire racing hub must still work.
