# FacetBench slice: 2026-10-15

This measurement has one run per arm on one slice, with seed 1 and
`gpt-6.1-sol` at medium effort. It does not establish a general Facet quality,
cost or performance claim. The judge result and human calibration labels are absent.

The saved runs are in
`artifacts/facetbench/slice/runs/racing-hub-slice/{plain,facet}/codex-sol/seed-1`.
The agents were not run again. Verify repeats only the hidden checks and
audits against each saved workspace. It archives the previous result, checks
and captures in that run's `rechecks` directory. Agent metrics, transcript,
timestamps and `agent.rbxlx` stay as recorded.

After the correction, Plain passes no universal device case. Facet passes the
purchase-and-wallet case on each device. Both builds still fail the complete
universal gate. These are recorded UI assertion failures, with the strong
reference passing the same checks. The report remains FAIL and judge evidence
remains missing.

## Check method

Verify retains valid case reports when a command fails. Each universal score
must match the selected device case records. Missing, repeated, or incomplete
records cause a harness error. Failed UI assertions retain their reasons and
scores. Failed Studio probe calls prevent score output.

Text geometry uses native `TextBounds`, alignment, and padding. Opaque paint
on a higher layer can hide text; ancestor paint does not hide its child text.
After a failed case, the driver uses visible return controls to close the route.
The failure remains in the report.

These audit counts use the collector before styled-property and modal-occlusion
analysis. They are measurements of the saved builds with that collector.

## Setup

The agent uses Codex CLI `0.162.0-alpha.17.2`. The tool versions are Lute
`1.0.1-nightly.20261006`, luau-lsp `1.69.0`, StyLua `2.5.2`, and Rojo `7.7.0`.
The projects use `Lighting.Technology = Future`. The play host starts and closes
its own Studio. The devices are `hd_1080` and portrait `iphone_14` simulations.

Both measured arms had the same scoped Studio MCP. It exposes only the
run-owned Studio and rejects other Studio identifiers. It supports play,
captures, Luau execution, native input and console output. The Facet arm also
had the Facet author tools. The scoped transport code is identical in both arms.

The original Facet run also hit an author-tool failure: `verify --tap Shop`
could not mount a probe because the generated kit lacked the driving-probe
dependency. Scoped Studio tools remained available. The saved run includes that failure and its cost. The current author kit includes the driving handler in `tools/play/engine`; it loads RaceTrack only for a driving request.

No judgment or human calibration label is present.
