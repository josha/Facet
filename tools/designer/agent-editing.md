# Agent edits

Agents can edit the portable component source generated by Facet Design. The
Studio plugin watches its linked ModuleScript. Supported edits update the canvas
and enter design history. Visual edits update that same source.

Run these commands from the repository root:

```sh
lune run tools/designer/edit inspect component.luau
lune run tools/designer/edit edit component.luau operations.json edited.luau
```

An operations file contains a JSON array:

```json
[
  {"op":"set","node":"Heading","property":"text","value":"Ready for adventure"},
  {"op":"set","node":"Preferences","property":"padding","value":{"top":16,"right":24,"bottom":16,"left":24}}
]
```

Select a node by its ID or a unique layer name. Operations include set, reset,
insert, remove, duplicate, move, and renameDesign. The agent module validates the
whole batch before it returns source. An invalid operation leaves the input
unchanged. A batch has at most 100 operations.

Apply the resulting source to the linked ModuleScript through Studio. File edits
alone do not update a ModuleScript unless the project has a file-sync connection.
The ModuleScript attribute FacetDesignSourceStatus reports synchronized or custom.
FacetDesignDocument contains the current supported authoring document.

Custom callbacks, external expressions, and arbitrary game code do not round
trip. The plugin retains custom source and pauses visual writes. Restore a
supported component before further visual edits.
