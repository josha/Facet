# ADR-0006: "Studio Neutral" default style + style-authority rendering

- **Status:** Accepted (2026-07-19, director direction: "if Apple made a game UI system — minimal but polished, affordances always clear, professional/neutral, renders quickly, motion in key areas by default")
- **Context:** The Phase 2 live drive showed the port rendering functionally-correct but visually flat against the game's own polished UI (screenshot `Phase2_SettingsPort_RealGame`, finding recorded in `artifacts/studio/phase2-port-drive.json`). Roblox's default UI look is poor; Facet should make every app professional by default while games override via tokens.
- **Decision:** `src/tokens/default_style.luau` ships a built-in compiled style ("Studio Neutral"): one cool near-black surface ramp, ONE restrained accent (contrast-gated 4.5:1+ — the compiler rejected the first accent candidate at 4.32:1), hairline strokes over borders, generous radii, motion tokens (fast 0.12/normal 0.2, ease-out) honored only where they inform (toggle knob, pressed dip, hover fills) and always reduced-motion-aware. Zero expensive effects: flat fills + one stroke per element, no gradients/blur/shadows.
  - Blueprint gains style-authority HINTS, not colors: `surface = "base"|"raised"|"control"|"scrim"` on containers, `role = "secondary"` on Text. The renderer pushes them through `authority.assertWrite(..., "style")`; visuals resolve ONLY inside the render adapter (ScreenTarget) — screens never pick colors (§7.3 one-authority holds).
  - ScreenTarget applies: surfaces (raised = panel radius + hairline; scrim = dimmed backdrop that strips control chrome and suppresses hover/press states), interactive rest/hover/pressed fills + UIScale pressed dip, a real Toggle knob-track (accent when on, animated), focus ring (accent UIStroke) driven by the logical focus graph via `controller.setFocusPath` (never color-only, §8.4), disabled = 40% content.
  - `screen_target.new({ style, isReducedMotion })` accepts a game-compiled override; default is Studio Neutral.
- **Evidence:** before/after screenshots `Phase2_SettingsPort_RealGame` vs `Phase2_SettingsPort_StudioNeutral` (real RascalRally place); library suite 114 green; game suite 2392 green.
- **Consequences:** every Facet surface gets the professional floor for free; StyleSheet generation remains deferred (§11 non-beta path). Polish item RESOLVED same day (director report): the toggle label now lives in a dedicated child TextLabel sized to clear the track (the button's own text region does not reliably honor UIPadding); verified via screenshot Phase2_SettingsPort_ToggleFix.
