# LevelPicker.card

Choose a level.

Inside an app mount, set `local UI = app.UI`.

```luau
UI.LevelPicker "LevelPicker" { value = Facet.Compose.cell(3) }
```

Key options: `value`, `count`, `onChange`.

Use a writable value for an editable choice.
