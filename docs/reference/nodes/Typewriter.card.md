# Typewriter.card

Reveal a line of text.

Inside an app mount, set `local UI = app.UI`.

```luau
UI.Typewriter "Typewriter" { text = "Follow the lights", wrap = true }
```

Key options: `text`, `rich`, `controls`, `onRevealed`.

Do not slice a rich text string to reveal it.

Related controls: [Controls](Controls.md).
