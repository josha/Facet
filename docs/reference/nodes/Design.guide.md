# Game UI design

Read Game UI design before planning, building, changing
or reviewing UI. The use-facet skill includes the guide and its chapters.

Open the main guide from the skill's directory:
`references/GAME_UI_DESIGN_GUIDE.md`.

| Installation | Guide path from the project root |
| --- | --- |
| Facet repository | `skills/use-facet/references/GAME_UI_DESIGN_GUIDE.md` |
| Exported author kit | `.agents/skills/use-facet/references/GAME_UI_DESIGN_GUIDE.md` |

Read the main guide unless already in context. Follow its chapter map to the
relevant chapters. For a new game, read the visual language chapter before
the first screen. For a local control choice, use the control map
(`references/CONTROL_MAP.md`) and compare the nearest alternatives. Do not
load every chapter by default.

The guide starts with principles, what Roblox changes and how Facet adapts
declared intent. It then works from the outside in: the flow, the attention
level of each surface, its composition, the visual language, elements, states,
feedback and each input's conventions, and ends with verification. Its
chapters cover moments of play, layout and navigation, surfaces, collections,
choices, direct manipulation, visual language, motion and input. Use
[Map](Map.md) for task recipes and exact control contracts. Check the rendered
result against the guide as well as the technical checks.
