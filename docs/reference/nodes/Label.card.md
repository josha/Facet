# Label.card

Show an icon with a title.

Inside an app mount, set `local UI = app.UI`.

```luau
UI.Label "Label" { title = "Inventory", icon = "person" }
```

Key options: `title`, `icon`, `presentation`.

Use title for the accessible name.
