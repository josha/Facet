# Avatar.card

Show a player or guest face.

Inside an app mount, set `local UI = app.UI`.

```luau
UI.Avatar "Avatar" { name = "Guest", icon = "person" }
```

Key options: `name`, `image`, `userId`, `presence`.

Choose one face source.
