# Image.card

Show an image.

Inside an app mount, set `local UI = app.UI`.

```luau
UI.Image "Image" { image = "rbxassetid://0" }
```

Key options: `image`, `scaleMode`, `tint`.

Use a valid game-owned asset.

Related controls: [Controls](Controls.md).
