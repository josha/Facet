# Glossy Touch

Prominent touch controls.

Use the game-owned builder in [glossy_touch](../../../examples/themes/glossy_touch.luau). Check its return contract before use.

The source defines this theme's tokens and builder options. A theme changes paint, type, spacing and motion.
Use the same package for the controls and the native StyleSheet.
