# StatusIndicator.card

Show a status mark.

Inside an app mount, set `local UI = app.UI`.

```luau
UI.StatusIndicator "StatusIndicator" { status = "success", name = "Ready" }
```

Key options: `status`, `form`, `count`, `name`.

Give the mark an accessible name.
