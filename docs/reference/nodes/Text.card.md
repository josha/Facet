# Text.card

Show text.

Inside an app mount, set `local UI = app.UI`.

```luau
UI.Text "Text" { text = "Ready", wrap = true }
```

Key options: `text`, `textRole`, `wrap`, `truncate`, `lines`.

Put wrapped text in a stack with width = fill. Text has no width option.
