# Text

Text.summary option values and behavior.

| Control | Main contract |
|---|---|
| `Text` | Plain text in a native TextLabel. `text` is required. `textRole` (or `textSize` as a role name) is one of `TYPE_ROLES`. `textSize` is also a pixel number or a fit form. `role` is `secondary` or `content`. Also `truncate`, `lines`, `textAlign`, `wrap`, `rich`, `direction`, `tint`, and native text properties. See [Text](Text.reference.md). |
