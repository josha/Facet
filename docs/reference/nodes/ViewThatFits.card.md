# ViewThatFits.card

Choose content that fits the room.

Inside an app mount, set `local UI = app.UI`.

```luau
UI.ViewThatFits "ViewThatFits" { UI.Text { text = "Ready" } }
```

Key options: `width`, `height`, numeric children.

Put the smallest form last.
