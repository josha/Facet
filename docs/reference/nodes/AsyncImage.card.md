# AsyncImage.card

Load an image with a placeholder.

Inside an app mount, set `local UI = app.UI`.

```luau
UI.AsyncImage "AsyncImage" { image = "rbxassetid://0" }
```

Key options: `image`, `loader`, `placeholder`, `onStatus`.

Forward native image props through imageProperties.

Related controls: [Controls](Controls.md).
