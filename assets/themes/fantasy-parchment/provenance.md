# Fantasy Parchment — source art provenance

**Stage:** `theme-packages-and-skinning` (Step 3.5) · **Created:** 2026-07-24

Every texture in this directory is **original, repository-owned, procedurally
generated art**. There is no external imagery, no third-party asset, no game or OS
trade dress. The single source is `tools/facet/art/fantasy_parchment.luau`: layered value noise,
stains, deckled-edge masks, and hand-jittered ink rules over a warm paper palette,
from the fixed seed `0x5EED`. Re-running the script reproduces the PNGs (byte-for-byte
on the same library versions).

| File | Size | Nine-slice border | Role |
|---|---|---|---|
| `parchment_panel.png` | 144×144 | 40 px | Raised panels, modals (framed page, double ink rule) |
| `parchment_button.png` | 64×64 | 16 px | Button/control chrome (tanned slab, heavy single rule) |
| `parchment_field.png` | 64×64 | 16 px | Text-field chrome (light writing surface, letterpress well, thin rule) |

Slice geometry is package data: `SliceCenter = Rect(border, border, size−border,
size−border)` with `SliceScale = 1`. Control borders are 16 px so both borders
(32 px) fit inside a 46 px-tall control without slice overlap.

**Regenerate:** `lute run tools/facet art fantasy-parchment` from the repository root.
`lute run tools/facet art fantasy-parchment --check` regenerates in memory and compares
every pixel with the committed files. The command writes only a file whose
pixels changed.

**Interaction states** are tints, not extra images: the theme's state rules modulate
`ImageColor3`/`ImageTransparency` over these bases (hover lightens, press darkens,
disabled desaturates via tint + text dim, error tints toward red ink). This keeps the
asset set minimal and the swap cost flat.

**Import/publishing:** upload each PNG as a Roblox Image asset (Studio asset manager
or the `upload_image` tooling); record the returned `rbxassetid://` content IDs in
the package's `assets` section (`upload-manifest.json` beside this file records the
IDs used by the repository package). Another project reproducing the package uploads
the same PNGs under its own account and substitutes its IDs — no hidden assets.

**License:** same license as the repository; the art is generated by repository code
and carries no external claims.

## Luau generator (2026-10-14)

The Python generator is replaced by `tools/facet/art/fantasy_parchment.luau`. The Facet raster library in
`tools/facet/lib/raster/` implements the Pillow drawing, resampling, blur
and PNG operations, and the numpy PCG64 random stream, that the generator uses.
It produces all 6 committed package PNGs pixel for pixel, so their bytes,
SHA-256 values and asset IDs did not change. Nothing was uploaded.
