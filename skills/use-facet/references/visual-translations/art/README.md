# Original artwork

The concepts and artwork were generated for these examples with OpenAI Image Generation. The art prompts are in [prompts](prompts/). The runtime subject illustrations and controls are separate images. The artwork contains no UI labels. The two shipped-game images used to compare visual craft were never used as art inputs or uploaded.

Both plate sheets were split on their transparent margins, cropped and resampled to the dimensions above. The two choice plates and raspberry ticket use slice center `(36, 26, 732, 130)` and slice scale `0.48`. The amber plate uses `(56, 43, 712, 113)` and scale `0.40` so each complete bolt stays in a fixed corner at the shortest action height. Each asset was uploaded as an Image through Roblox Open Cloud to user creator 1364639953.
