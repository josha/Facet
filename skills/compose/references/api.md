# Public API

For a component and the runtime setup, start with the [quickstart](https://github.com/voidmeld/compose/blob/1a7930a4977360c1df2849b64c6e267895a5a8ad/docs/quickstart.md).
For calls, types and failure behavior, use the [API reference](https://github.com/voidmeld/compose/blob/1a7930a4977360c1df2849b64c6e267895a5a8ad/docs/api.md).
Host constructors belong to the runtime. Reactive helpers belong to core.

To change Compose itself, follow [AGENTS](https://github.com/voidmeld/compose/blob/1a7930a4977360c1df2849b64c6e267895a5a8ad/AGENTS.md).
