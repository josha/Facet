# Public API

For a component and the runtime setup, start with the [quickstart](https://github.com/voidmeld/compose/blob/2c8a89896db550326fd4c927479ac1672305bb0d/docs/quickstart.md).
For calls, types and failure behavior, use the [API reference](https://github.com/voidmeld/compose/blob/2c8a89896db550326fd4c927479ac1672305bb0d/docs/api.md).
Host constructors belong to the runtime. Reactive helpers belong to core.

To change Compose itself, follow [AGENTS](https://github.com/voidmeld/compose/blob/2c8a89896db550326fd4c927479ac1672305bb0d/AGENTS.md).
