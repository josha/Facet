# Public API

For a component and the runtime setup, start with the [quickstart](https://github.com/voidmeld/compose/blob/0624ea75a92602f191a2c82009533fee5d81d80f/docs/quickstart.md).
For calls, types and failure behavior, use the [API reference](https://github.com/voidmeld/compose/blob/0624ea75a92602f191a2c82009533fee5d81d80f/docs/api.md).
Host constructors belong to the runtime. Reactive helpers belong to core.

To change Compose itself, follow [AGENTS](https://github.com/voidmeld/compose/blob/0624ea75a92602f191a2c82009533fee5d81d80f/AGENTS.md).
