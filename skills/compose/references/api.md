# Public API

For a component and the runtime setup, start with the [quickstart](https://github.com/voidmeld/compose/blob/147835f88b216b7348e0ab1a9866a4cfea66af7f/docs/quickstart.md).
For calls, types and failure behavior, use the [API reference](https://github.com/voidmeld/compose/blob/147835f88b216b7348e0ab1a9866a4cfea66af7f/docs/api.md).
Host constructors belong to the runtime. Reactive helpers belong to core.

To change Compose itself, follow [AGENTS](https://github.com/voidmeld/compose/blob/147835f88b216b7348e0ab1a9866a4cfea66af7f/AGENTS.md).
