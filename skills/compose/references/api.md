# Public API

For a component and the runtime setup, start with the [quickstart](https://github.com/voidmeld/compose/blob/ae9bc66c686606a3d6e20932b93b1c9a68f9f8d5/docs/quickstart.md).
For calls, types and failure behavior, use the [API reference](https://github.com/voidmeld/compose/blob/ae9bc66c686606a3d6e20932b93b1c9a68f9f8d5/docs/api.md).
Host constructors belong to the runtime. Reactive helpers belong to core.

To change Compose itself, follow [AGENTS](https://github.com/voidmeld/compose/blob/ae9bc66c686606a3d6e20932b93b1c9a68f9f8d5/AGENTS.md).
