# Public API

For a component and the runtime setup, start with the [quickstart](https://github.com/voidmeld/compose/blob/36acaafa0f600f012656f1bf38182cf22c14e728/docs/quickstart.md).
For calls, types and failure behavior, use the [API reference](https://github.com/voidmeld/compose/blob/36acaafa0f600f012656f1bf38182cf22c14e728/docs/api.md).
Host constructors belong to the runtime. Reactive helpers belong to core.

To change Compose itself, follow [AGENTS](https://github.com/voidmeld/compose/blob/36acaafa0f600f012656f1bf38182cf22c14e728/AGENTS.md).
