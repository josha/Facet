# Public API

For a component and the runtime setup, start with the [quickstart](https://github.com/voidmeld/compose/blob/32a1af22f909267345b061dc29c299d656ed1e25/docs/quickstart.md).
For calls, types and failure behavior, use the [API reference](https://github.com/voidmeld/compose/blob/32a1af22f909267345b061dc29c299d656ed1e25/docs/api.md).
Host constructors belong to the runtime. Reactive helpers belong to core.

To change Compose itself, follow [AGENTS](https://github.com/voidmeld/compose/blob/32a1af22f909267345b061dc29c299d656ed1e25/AGENTS.md).
