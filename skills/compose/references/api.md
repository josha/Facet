# Public API

For a component and the runtime setup, start with the [quickstart](https://github.com/voidmeld/compose/blob/a526574b18c51810dc9c99ded26235cdea9a9c5b/docs/quickstart.md).
For calls, types and failure behavior, use the [API reference](https://github.com/voidmeld/compose/blob/a526574b18c51810dc9c99ded26235cdea9a9c5b/docs/api.md).
Host constructors belong to the runtime. Reactive helpers belong to core.

To change Compose itself, follow [AGENTS](https://github.com/voidmeld/compose/blob/a526574b18c51810dc9c99ded26235cdea9a9c5b/AGENTS.md).
