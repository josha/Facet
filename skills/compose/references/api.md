# Public API

For a component and the runtime setup, start with the [quickstart](https://github.com/voidmeld/compose/blob/1667ae2fb154994a88b0ecbbc5e5cfb95cb23003/docs/quickstart.md).
For calls, types and failure behavior, use the [API reference](https://github.com/voidmeld/compose/blob/1667ae2fb154994a88b0ecbbc5e5cfb95cb23003/docs/api.md).
Host constructors belong to the runtime. Reactive helpers belong to core.

To change Compose itself, follow [AGENTS](https://github.com/voidmeld/compose/blob/1667ae2fb154994a88b0ecbbc5e5cfb95cb23003/AGENTS.md).
