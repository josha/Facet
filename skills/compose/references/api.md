# Public API

For a component and the runtime setup, start with the [quickstart](https://github.com/voidmeld/compose/blob/2bfff237653f55eddfc353513ac527595acd93a0/docs/quickstart.md).
For calls, types and failure behavior, use the [API reference](https://github.com/voidmeld/compose/blob/2bfff237653f55eddfc353513ac527595acd93a0/docs/api.md).
Host constructors belong to the runtime. Reactive helpers belong to core.

To change Compose itself, follow [AGENTS](https://github.com/voidmeld/compose/blob/2bfff237653f55eddfc353513ac527595acd93a0/AGENTS.md).
