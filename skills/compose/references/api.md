# Public API

For a component and the runtime setup, start with the [quickstart](https://github.com/voidmeld/compose/blob/76eccc20c54010b1ede63f96c07949c2ee799d0a/docs/quickstart.md).
For calls, types and failure behavior, use the [API reference](https://github.com/voidmeld/compose/blob/76eccc20c54010b1ede63f96c07949c2ee799d0a/docs/api.md).
Host constructors belong to the runtime. Reactive helpers belong to core.

To change Compose itself, follow [AGENTS](https://github.com/voidmeld/compose/blob/76eccc20c54010b1ede63f96c07949c2ee799d0a/AGENTS.md).
