# Public API

For a component and the runtime setup, start with the [quickstart](https://github.com/voidmeld/compose/blob/95bb81aac2f21be1d79a3be1458aac98d93d45ef/docs/quickstart.md).
For calls, types and failure behavior, use the [API reference](https://github.com/voidmeld/compose/blob/95bb81aac2f21be1d79a3be1458aac98d93d45ef/docs/api.md).
Host constructors belong to the runtime. Reactive helpers belong to core.

To change Compose itself, follow [AGENTS](https://github.com/voidmeld/compose/blob/95bb81aac2f21be1d79a3be1458aac98d93d45ef/AGENTS.md).
