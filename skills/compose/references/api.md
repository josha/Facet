# Public API

For a component and the runtime setup, start with the [quickstart](https://github.com/voidmeld/compose/blob/249a31dc1a2895ebe99ae56667b43c3064129a39/docs/quickstart.md).
For calls, types and failure behavior, use the [API reference](https://github.com/voidmeld/compose/blob/249a31dc1a2895ebe99ae56667b43c3064129a39/docs/api.md).
Host constructors belong to the runtime. Reactive helpers belong to core.

To change Compose itself, follow [AGENTS](https://github.com/voidmeld/compose/blob/249a31dc1a2895ebe99ae56667b43c3064129a39/AGENTS.md).
