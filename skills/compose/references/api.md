# Public API

For a component and the runtime setup, start with the [quickstart](https://github.com/voidmeld/compose/blob/a2776091d4a4d27268ea3ec6a40a8eed87275412/docs/quickstart.md).
For calls, types and failure behavior, use the [API reference](https://github.com/voidmeld/compose/blob/a2776091d4a4d27268ea3ec6a40a8eed87275412/docs/api.md).
Host constructors belong to the runtime. Reactive helpers belong to core.

To change Compose itself, follow [AGENTS](https://github.com/voidmeld/compose/blob/a2776091d4a4d27268ea3ec6a40a8eed87275412/AGENTS.md).
