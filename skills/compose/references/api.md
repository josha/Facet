# Public API

For a component and the runtime setup, start with the [quickstart](https://github.com/voidmeld/compose/blob/1615759a6778ef194b0e14365c34cee4c9ffacf8/docs/quickstart.md).
For calls, types and failure behavior, use the [API reference](https://github.com/voidmeld/compose/blob/1615759a6778ef194b0e14365c34cee4c9ffacf8/docs/api.md).
Host constructors belong to the runtime. Reactive helpers belong to core.

To change Compose itself, follow [AGENTS](https://github.com/voidmeld/compose/blob/1615759a6778ef194b0e14365c34cee4c9ffacf8/AGENTS.md).
