# Public API

For a component and the runtime setup, start with the [quickstart](https://github.com/voidmeld/compose/blob/f84dcb909efac0c54bfb349b1276be5b26c9cb50/docs/quickstart.md).
For calls, types and failure behavior, use the [API reference](https://github.com/voidmeld/compose/blob/f84dcb909efac0c54bfb349b1276be5b26c9cb50/docs/api.md).
Host constructors belong to the runtime. Reactive helpers belong to core.

To change Compose itself, follow [AGENTS](https://github.com/voidmeld/compose/blob/f84dcb909efac0c54bfb349b1276be5b26c9cb50/AGENTS.md).
