# Public API

For a component and the runtime setup, start with the [quickstart](https://github.com/voidmeld/compose/blob/8cd36561bb04f4124d957750929abea9e4fb7c25/docs/quickstart.md).
For calls, types and failure behavior, use the [API reference](https://github.com/voidmeld/compose/blob/8cd36561bb04f4124d957750929abea9e4fb7c25/docs/api.md).
Host constructors belong to the runtime. Reactive helpers belong to core.

To change Compose itself, follow [AGENTS](https://github.com/voidmeld/compose/blob/8cd36561bb04f4124d957750929abea9e4fb7c25/AGENTS.md).
