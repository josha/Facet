# Public API

For a component and the runtime setup, start with the [quickstart](https://github.com/voidmeld/compose/blob/713ba9226e2157a0365ab52a209292fc53d4ae9c/docs/quickstart.md).
For calls, types and failure behavior, use the [API reference](https://github.com/voidmeld/compose/blob/713ba9226e2157a0365ab52a209292fc53d4ae9c/docs/api.md).
Host constructors belong to the runtime. Reactive helpers belong to core.

To change Compose itself, follow [AGENTS](https://github.com/voidmeld/compose/blob/713ba9226e2157a0365ab52a209292fc53d4ae9c/AGENTS.md).
