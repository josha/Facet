# Public API

For a component and the runtime setup, start with the [quickstart](https://github.com/voidmeld/compose/blob/e3bfb56c21e4b1a284e6e918edcd0ac364d1e569/docs/quickstart.md).
For calls, types and failure behavior, use the [API reference](https://github.com/voidmeld/compose/blob/e3bfb56c21e4b1a284e6e918edcd0ac364d1e569/docs/api.md).
Host constructors belong to the runtime. Reactive helpers belong to core.

To change Compose itself, follow [AGENTS](https://github.com/voidmeld/compose/blob/e3bfb56c21e4b1a284e6e918edcd0ac364d1e569/AGENTS.md).
