# Public API

For a component and the runtime setup, start with the [quickstart](https://github.com/voidmeld/compose/blob/5945400d3c5d134d92f778cf8628b821187f254e/docs/quickstart.md).
For calls, types and failure behavior, use the [API reference](https://github.com/voidmeld/compose/blob/5945400d3c5d134d92f778cf8628b821187f254e/docs/api.md).
Host constructors belong to the runtime. Reactive helpers belong to core.

To change Compose itself, follow [AGENTS](https://github.com/voidmeld/compose/blob/5945400d3c5d134d92f778cf8628b821187f254e/AGENTS.md).
