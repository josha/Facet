# Public API

For a component and the runtime setup, start with the [quickstart](https://github.com/voidmeld/compose/blob/1f20ddae60cf25df2faa5a9520f4bd5ad522de4b/docs/quickstart.md).
For calls, types and failure behavior, use the [API reference](https://github.com/voidmeld/compose/blob/1f20ddae60cf25df2faa5a9520f4bd5ad522de4b/docs/api.md).
Host constructors belong to the runtime. Reactive helpers belong to core.

To change Compose itself, follow [AGENTS](https://github.com/voidmeld/compose/blob/1f20ddae60cf25df2faa5a9520f4bd5ad522de4b/AGENTS.md).
