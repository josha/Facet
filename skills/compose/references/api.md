# Public API

For a component and the runtime setup, start with the [quickstart](https://github.com/voidmeld/compose/blob/88668fff676fbc4d4736341f1c18aaccc43e974c/docs/quickstart.md).
For calls, types and failure behavior, use the [API reference](https://github.com/voidmeld/compose/blob/88668fff676fbc4d4736341f1c18aaccc43e974c/docs/api.md).
Host constructors belong to the runtime. Reactive helpers belong to core.

To change Compose itself, follow [AGENTS](https://github.com/voidmeld/compose/blob/88668fff676fbc4d4736341f1c18aaccc43e974c/AGENTS.md).
