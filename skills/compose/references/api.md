# Public API

For a component and the runtime setup, start with the [quickstart](https://github.com/voidmeld/compose/blob/ad5fe3a8d8d34c092c0f2b3ba2857b4856df069d/docs/quickstart.md).
For calls, types and failure behavior, use the [API reference](https://github.com/voidmeld/compose/blob/ad5fe3a8d8d34c092c0f2b3ba2857b4856df069d/docs/api.md).
Host constructors belong to the runtime. Reactive helpers belong to core.

To change Compose itself, follow [AGENTS](https://github.com/voidmeld/compose/blob/ad5fe3a8d8d34c092c0f2b3ba2857b4856df069d/AGENTS.md).
