# Public API

For a component and the runtime setup, start with the [quickstart](https://github.com/voidmeld/compose/blob/b1c92f3165d88d62b6a196a2eaa548bb4e98689f/docs/quickstart.md).
For calls, types and failure behavior, use the [API reference](https://github.com/voidmeld/compose/blob/b1c92f3165d88d62b6a196a2eaa548bb4e98689f/docs/api.md).
Host constructors belong to the runtime. Reactive helpers belong to core.

To change Compose itself, follow [AGENTS](https://github.com/voidmeld/compose/blob/b1c92f3165d88d62b6a196a2eaa548bb4e98689f/AGENTS.md).
