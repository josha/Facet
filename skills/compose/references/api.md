# Public API

For a component and the runtime setup, start with the [quickstart](https://github.com/voidmeld/compose/blob/514a3bd6ec89ed215f55e651fe6b8c11cbeb5175/docs/quickstart.md).
For calls, types and failure behavior, use the [API reference](https://github.com/voidmeld/compose/blob/514a3bd6ec89ed215f55e651fe6b8c11cbeb5175/docs/api.md).
Host constructors belong to the runtime. Reactive helpers belong to core.

To change Compose itself, follow [AGENTS](https://github.com/voidmeld/compose/blob/514a3bd6ec89ed215f55e651fe6b8c11cbeb5175/AGENTS.md).
