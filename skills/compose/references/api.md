# Public API

For a component and the runtime setup, start with the [quickstart](https://github.com/voidmeld/compose/blob/9c6f1e0b8961d29cb6234e1e798ae152bfaa05f9/docs/quickstart.md).
For calls, types and failure behavior, use the [API reference](https://github.com/voidmeld/compose/blob/9c6f1e0b8961d29cb6234e1e798ae152bfaa05f9/docs/api.md).
Host constructors belong to the runtime. Reactive helpers belong to core.

To change Compose itself, follow [AGENTS](https://github.com/voidmeld/compose/blob/9c6f1e0b8961d29cb6234e1e798ae152bfaa05f9/AGENTS.md).
