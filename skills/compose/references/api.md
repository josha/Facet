# Public API

For a component and the runtime setup, start with the [quickstart](https://github.com/voidmeld/compose/blob/885b11f52972c9153bd40bb6b7b64ef7a264a7ee/docs/quickstart.md).
For calls, types and failure behavior, use the [API reference](https://github.com/voidmeld/compose/blob/885b11f52972c9153bd40bb6b7b64ef7a264a7ee/docs/api.md).
Host constructors belong to the runtime. Reactive helpers belong to core.

To change Compose itself, follow [AGENTS](https://github.com/voidmeld/compose/blob/885b11f52972c9153bd40bb6b7b64ef7a264a7ee/AGENTS.md).
