# Public API

For a component and the runtime setup, start with the [quickstart](https://github.com/voidmeld/compose/blob/e3c942cb1490f8b7bfc1af59e40cb20d447cd233/docs/quickstart.md).
For calls, types and failure behavior, use the [API reference](https://github.com/voidmeld/compose/blob/e3c942cb1490f8b7bfc1af59e40cb20d447cd233/docs/api.md).
Host constructors belong to the runtime. Reactive helpers belong to core.

To change Compose itself, follow [AGENTS](https://github.com/voidmeld/compose/blob/e3c942cb1490f8b7bfc1af59e40cb20d447cd233/AGENTS.md).
