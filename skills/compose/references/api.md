# Public API

For a component and the runtime setup, start with the [quickstart](https://github.com/voidmeld/compose/blob/ed40b1034d0cb14cdf442e1f6129ea6cb12bcc52/docs/quickstart.md).
For calls, types and failure behavior, use the [API reference](https://github.com/voidmeld/compose/blob/ed40b1034d0cb14cdf442e1f6129ea6cb12bcc52/docs/api.md).
Host constructors belong to the runtime. Reactive helpers belong to core.

To change Compose itself, follow [AGENTS](https://github.com/voidmeld/compose/blob/ed40b1034d0cb14cdf442e1f6129ea6cb12bcc52/AGENTS.md).
