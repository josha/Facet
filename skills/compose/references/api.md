# Public API

For a component and the runtime setup, start with the [quickstart](https://github.com/voidmeld/compose/blob/61098e981dd96368025b6f14e7d40cdf9a3d439e/docs/quickstart.md).
For calls, types and failure behavior, use the [API reference](https://github.com/voidmeld/compose/blob/61098e981dd96368025b6f14e7d40cdf9a3d439e/docs/api.md).
Host constructors belong to the runtime. Reactive helpers belong to core.

To change Compose itself, follow [AGENTS](https://github.com/voidmeld/compose/blob/61098e981dd96368025b6f14e7d40cdf9a3d439e/AGENTS.md).
