# Public API

For a component and the runtime setup, start with the [quickstart](https://github.com/voidmeld/compose/blob/0e0d939871fb7cb528f6ce0ac4917662424d1708/docs/quickstart.md).
For calls, types and failure behavior, use the [API reference](https://github.com/voidmeld/compose/blob/0e0d939871fb7cb528f6ce0ac4917662424d1708/docs/api.md).
Host constructors belong to the runtime. Reactive helpers belong to core.

To change Compose itself, follow [AGENTS](https://github.com/voidmeld/compose/blob/0e0d939871fb7cb528f6ce0ac4917662424d1708/AGENTS.md).
