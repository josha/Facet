# Public API

For a component and the runtime setup, start with the [quickstart](https://github.com/voidmeld/compose/blob/e50a4096518be8328d412e240e5abe6f64f6e89f/docs/quickstart.md).
For calls, types and failure behavior, use the [API reference](https://github.com/voidmeld/compose/blob/e50a4096518be8328d412e240e5abe6f64f6e89f/docs/api.md).
Host constructors belong to the runtime. Reactive helpers belong to core.

To change Compose itself, follow [AGENTS](https://github.com/voidmeld/compose/blob/e50a4096518be8328d412e240e5abe6f64f6e89f/AGENTS.md).
