# Public API

For a component and the runtime setup, start with the [quickstart](https://github.com/voidmeld/compose/blob/8b93ea4cb00aa5874d88744084b406755edb8c18/docs/quickstart.md).
For calls, types and failure behavior, use the [API reference](https://github.com/voidmeld/compose/blob/8b93ea4cb00aa5874d88744084b406755edb8c18/docs/api.md).
Host constructors belong to the runtime. Reactive helpers belong to core.

To change Compose itself, follow [AGENTS](https://github.com/voidmeld/compose/blob/8b93ea4cb00aa5874d88744084b406755edb8c18/AGENTS.md).
