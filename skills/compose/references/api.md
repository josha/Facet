# Public API

For a component and the runtime setup, start with the [quickstart](https://github.com/voidmeld/compose/blob/d645e280238a30e19920013739675e0d710a6940/docs/quickstart.md).
For calls, types and failure behavior, use the [API reference](https://github.com/voidmeld/compose/blob/d645e280238a30e19920013739675e0d710a6940/docs/api.md).
For typed node bindings in emitted documents, see [Design.emit](https://github.com/voidmeld/compose/blob/d645e280238a30e19920013739675e0d710a6940/docs/api.md#designemit).
For static enum root variants, see [Design.document](https://github.com/voidmeld/compose/blob/d645e280238a30e19920013739675e0d710a6940/docs/api.md#designdocument).
For numeric input and token components, see [Design.datatype](https://github.com/voidmeld/compose/blob/d645e280238a30e19920013739675e0d710a6940/docs/api.md#designdatatype).
Host constructors belong to the runtime. Reactive helpers belong to core.

To change Compose itself, follow [AGENTS](https://github.com/voidmeld/compose/blob/d645e280238a30e19920013739675e0d710a6940/AGENTS.md).
