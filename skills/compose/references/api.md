# Public API

For a component and the runtime setup, start with the [quickstart](https://github.com/voidmeld/compose/blob/8a1ed67ea6ae71807a2c00cf7bc6f35d4479b472/docs/quickstart.md).
For calls, types and failure behavior, use the [API reference](https://github.com/voidmeld/compose/blob/8a1ed67ea6ae71807a2c00cf7bc6f35d4479b472/docs/api.md).
Host constructors belong to the runtime. Reactive helpers belong to core.

To change Compose itself, follow [AGENTS](https://github.com/voidmeld/compose/blob/8a1ed67ea6ae71807a2c00cf7bc6f35d4479b472/AGENTS.md).
