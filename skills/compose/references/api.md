# Public API

For a component and the runtime setup, start with the [quickstart](https://github.com/voidmeld/compose/blob/9a6c11fac10955ddf07e514316226fb40aed3dfe/docs/quickstart.md).
For calls, types and failure behavior, use the [API reference](https://github.com/voidmeld/compose/blob/9a6c11fac10955ddf07e514316226fb40aed3dfe/docs/api.md).
Host constructors belong to the runtime. Reactive helpers belong to core.

To change Compose itself, follow [AGENTS](https://github.com/voidmeld/compose/blob/9a6c11fac10955ddf07e514316226fb40aed3dfe/AGENTS.md).
