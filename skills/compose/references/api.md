# Public API

For a component and the runtime setup, start with the [quickstart](https://github.com/voidmeld/compose/blob/0e4848e793a2caede121d6dad0b21ecba8185c04/docs/quickstart.md).
For calls, types and failure behavior, use the [API reference](https://github.com/voidmeld/compose/blob/0e4848e793a2caede121d6dad0b21ecba8185c04/docs/api.md).
Host constructors belong to the runtime. Reactive helpers belong to core.

To change Compose itself, follow [AGENTS](https://github.com/voidmeld/compose/blob/0e4848e793a2caede121d6dad0b21ecba8185c04/AGENTS.md).
