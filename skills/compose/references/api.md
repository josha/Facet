# Public API

For a component and the runtime setup, start with the [quickstart](https://github.com/voidmeld/compose/blob/6b50d4967f1ac710c1c58d74545960d038f22b1f/docs/quickstart.md).
For calls, types and failure behavior, use the [API reference](https://github.com/voidmeld/compose/blob/6b50d4967f1ac710c1c58d74545960d038f22b1f/docs/api.md).
Host constructors belong to the runtime. Reactive helpers belong to core.

To change Compose itself, follow [AGENTS](https://github.com/voidmeld/compose/blob/6b50d4967f1ac710c1c58d74545960d038f22b1f/AGENTS.md).
