# Public API

For a component and the runtime setup, start with the [quickstart](https://github.com/voidmeld/compose/blob/7674be4f4f78cf71119b8a6f66980b6df0a8a94e/docs/quickstart.md).
For calls, types and failure behavior, use the [API reference](https://github.com/voidmeld/compose/blob/7674be4f4f78cf71119b8a6f66980b6df0a8a94e/docs/api.md).
Host constructors belong to the runtime. Reactive helpers belong to core.

To change Compose itself, follow [AGENTS](https://github.com/voidmeld/compose/blob/7674be4f4f78cf71119b8a6f66980b6df0a8a94e/AGENTS.md).
