# Public API

For a component and the runtime setup, start with the [quickstart](https://github.com/voidmeld/compose/blob/c872f38ad12a73087175caccd3025d2fc9e18393/docs/quickstart.md).
For calls, types and failure behavior, use the [API reference](https://github.com/voidmeld/compose/blob/c872f38ad12a73087175caccd3025d2fc9e18393/docs/api.md).
Host constructors belong to the runtime. Reactive helpers belong to core.

To change Compose itself, follow [AGENTS](https://github.com/voidmeld/compose/blob/c872f38ad12a73087175caccd3025d2fc9e18393/AGENTS.md).
