# Public API

For a component and the runtime setup, start with the [quickstart](https://github.com/voidmeld/compose/blob/083faaa21fe4886311c1150a7d09e184173148d1/docs/quickstart.md).
For calls, types and failure behavior, use the [API reference](https://github.com/voidmeld/compose/blob/083faaa21fe4886311c1150a7d09e184173148d1/docs/api.md).
Host constructors belong to the runtime. Reactive helpers belong to core.

To change Compose itself, follow [AGENTS](https://github.com/voidmeld/compose/blob/083faaa21fe4886311c1150a7d09e184173148d1/AGENTS.md).
