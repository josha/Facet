# Public API

For a component and the runtime setup, start with the [quickstart](https://github.com/voidmeld/compose/blob/ee44a2e5499f81790a0d495d3442f99e573bb8c9/docs/quickstart.md).
For calls, types and failure behavior, use the [API reference](https://github.com/voidmeld/compose/blob/ee44a2e5499f81790a0d495d3442f99e573bb8c9/docs/api.md).
Host constructors belong to the runtime. Reactive helpers belong to core.

To change Compose itself, follow [AGENTS](https://github.com/voidmeld/compose/blob/ee44a2e5499f81790a0d495d3442f99e573bb8c9/AGENTS.md).
