# Public API

For a component and the runtime setup, start with the [quickstart](https://github.com/voidmeld/compose/blob/95677df5b4f09dfec34b643dbda96de189abbc7b/docs/quickstart.md).
For calls, types and failure behavior, use the [API reference](https://github.com/voidmeld/compose/blob/95677df5b4f09dfec34b643dbda96de189abbc7b/docs/api.md).
Host constructors belong to the runtime. Reactive helpers belong to core.

To change Compose itself, follow [AGENTS](https://github.com/voidmeld/compose/blob/95677df5b4f09dfec34b643dbda96de189abbc7b/AGENTS.md).
