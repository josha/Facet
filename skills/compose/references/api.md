# Public API

For a component and the runtime setup, start with the [quickstart](https://github.com/voidmeld/compose/blob/1836eaaa4da1e39046d9a3176be768890cf50731/docs/quickstart.md).
For calls, types and failure behavior, use the [API reference](https://github.com/voidmeld/compose/blob/1836eaaa4da1e39046d9a3176be768890cf50731/docs/api.md).
Host constructors belong to the runtime. Reactive helpers belong to core.

To change Compose itself, follow [AGENTS](https://github.com/voidmeld/compose/blob/1836eaaa4da1e39046d9a3176be768890cf50731/AGENTS.md).
