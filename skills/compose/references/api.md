# Public API

For a component and the runtime setup, start with the [quickstart](https://github.com/voidmeld/compose/blob/79f32d61c4c6dd15e76efb01681ba308d55c52c6/docs/quickstart.md).
For calls, types and failure behavior, use the [API reference](https://github.com/voidmeld/compose/blob/79f32d61c4c6dd15e76efb01681ba308d55c52c6/docs/api.md).
Host constructors belong to the runtime. Reactive helpers belong to core.

To change Compose itself, follow [AGENTS](https://github.com/voidmeld/compose/blob/79f32d61c4c6dd15e76efb01681ba308d55c52c6/AGENTS.md).
