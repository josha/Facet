# Public API

For a component and the runtime setup, start with the [quickstart](https://github.com/voidmeld/compose/blob/d74f653e67baf9b22872a8161a0e010c4db7c750/docs/quickstart.md).
For calls, types and failure behavior, use the [API reference](https://github.com/voidmeld/compose/blob/d74f653e67baf9b22872a8161a0e010c4db7c750/docs/api.md).
Host constructors belong to the runtime. Reactive helpers belong to core.

To change Compose itself, follow [AGENTS](https://github.com/voidmeld/compose/blob/d74f653e67baf9b22872a8161a0e010c4db7c750/AGENTS.md).
