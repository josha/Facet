# Public API

For a component and the runtime setup, start with the [quickstart](https://github.com/voidmeld/compose/blob/0b2af86b4d5c07321c6bf31b5b35fe5ff73ab0d4/docs/quickstart.md).
For calls, types and failure behavior, use the [API reference](https://github.com/voidmeld/compose/blob/0b2af86b4d5c07321c6bf31b5b35fe5ff73ab0d4/docs/api.md).
Host constructors belong to the runtime. Reactive helpers belong to core.

To change Compose itself, follow [AGENTS](https://github.com/voidmeld/compose/blob/0b2af86b4d5c07321c6bf31b5b35fe5ff73ab0d4/AGENTS.md).
