# Public API

For a component and the runtime setup, start with the [quickstart](https://github.com/voidmeld/compose/blob/a5f0a9497d19a52340af87ce85e38066c7f9bbc9/docs/quickstart.md).
For calls, types and failure behavior, use the [API reference](https://github.com/voidmeld/compose/blob/a5f0a9497d19a52340af87ce85e38066c7f9bbc9/docs/api.md).
For typed node bindings in emitted documents, see [Design.emit](https://github.com/voidmeld/compose/blob/a5f0a9497d19a52340af87ce85e38066c7f9bbc9/docs/api.md#designemit).
For static enum root variants, see [Design.document](https://github.com/voidmeld/compose/blob/a5f0a9497d19a52340af87ce85e38066c7f9bbc9/docs/api.md#designdocument).
For numeric input and token components, see [Design.datatype](https://github.com/voidmeld/compose/blob/a5f0a9497d19a52340af87ce85e38066c7f9bbc9/docs/api.md#designdatatype).
Host constructors belong to the runtime. Reactive helpers belong to core.

To change Compose itself, follow [AGENTS](https://github.com/voidmeld/compose/blob/a5f0a9497d19a52340af87ce85e38066c7f9bbc9/AGENTS.md).
