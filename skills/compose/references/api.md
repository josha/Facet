# Public API

For a component and the runtime setup, start with the [quickstart](https://github.com/voidmeld/compose/blob/2d03ca1f097bc99efacefa5da74c51fea3ab78e7/docs/quickstart.md).
For calls, types and failure behavior, use the [API reference](https://github.com/voidmeld/compose/blob/2d03ca1f097bc99efacefa5da74c51fea3ab78e7/docs/api.md).
Host constructors belong to the runtime. Reactive helpers belong to core.

To change Compose itself, follow [AGENTS](https://github.com/voidmeld/compose/blob/2d03ca1f097bc99efacefa5da74c51fea3ab78e7/AGENTS.md).
