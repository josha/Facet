# Public API

For a component and the runtime setup, start with the [quickstart](https://github.com/voidmeld/compose/blob/0e3ca078f5052b1bc2cfef879ffd40f8850de6b9/docs/quickstart.md).
For calls, types and failure behavior, use the [API reference](https://github.com/voidmeld/compose/blob/0e3ca078f5052b1bc2cfef879ffd40f8850de6b9/docs/api.md).
Host constructors belong to the runtime. Reactive helpers belong to core.

To change Compose itself, follow [AGENTS](https://github.com/voidmeld/compose/blob/0e3ca078f5052b1bc2cfef879ffd40f8850de6b9/AGENTS.md).
