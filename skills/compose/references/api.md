# Public API

For a component and the runtime setup, start with the [quickstart](https://github.com/voidmeld/compose/blob/185bc974fc2ba6b153fd6af047419fe7687ebad4/docs/quickstart.md).
For calls, types and failure behavior, use the [API reference](https://github.com/voidmeld/compose/blob/185bc974fc2ba6b153fd6af047419fe7687ebad4/docs/api.md).
Host constructors belong to the runtime. Reactive helpers belong to core.

To change Compose itself, follow [AGENTS](https://github.com/voidmeld/compose/blob/185bc974fc2ba6b153fd6af047419fe7687ebad4/AGENTS.md).
