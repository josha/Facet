# Public API

For a component and the runtime setup, start with the [quickstart](https://github.com/voidmeld/compose/blob/e4fcb69b238929d042726b16f44d2d25278bb7b4/docs/quickstart.md).
For calls, types and failure behavior, use the [API reference](https://github.com/voidmeld/compose/blob/e4fcb69b238929d042726b16f44d2d25278bb7b4/docs/api.md).
Host constructors belong to the runtime. Reactive helpers belong to core.

To change Compose itself, follow [AGENTS](https://github.com/voidmeld/compose/blob/e4fcb69b238929d042726b16f44d2d25278bb7b4/AGENTS.md).
