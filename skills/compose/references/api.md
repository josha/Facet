# Public API

For a component and the runtime setup, start with the [quickstart](https://github.com/voidmeld/compose/blob/0660763fd9a7296fd4320c032998431a4e3d3809/docs/quickstart.md).
For calls, types and failure behavior, use the [API reference](https://github.com/voidmeld/compose/blob/0660763fd9a7296fd4320c032998431a4e3d3809/docs/api.md).
Host constructors belong to the runtime. Reactive helpers belong to core.

To change Compose itself, follow [AGENTS](https://github.com/voidmeld/compose/blob/0660763fd9a7296fd4320c032998431a4e3d3809/AGENTS.md).
