# Public API

For a component and the runtime setup, start with the [quickstart](https://github.com/voidmeld/compose/blob/47701aea4dc2fadf3b281f688ff7496cb879dbf1/docs/quickstart.md).
For calls, types and failure behavior, use the [API reference](https://github.com/voidmeld/compose/blob/47701aea4dc2fadf3b281f688ff7496cb879dbf1/docs/api.md).
Host constructors belong to the runtime. Reactive helpers belong to core.

To change Compose itself, follow [AGENTS](https://github.com/voidmeld/compose/blob/47701aea4dc2fadf3b281f688ff7496cb879dbf1/AGENTS.md).
