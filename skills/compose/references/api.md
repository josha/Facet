# Public API

For a component and the runtime setup, start with the [quickstart](https://github.com/voidmeld/compose/blob/df13c632df6e021ec7258199c1896b2d7e8421d0/docs/quickstart.md).
For calls, types and failure behavior, use the [API reference](https://github.com/voidmeld/compose/blob/df13c632df6e021ec7258199c1896b2d7e8421d0/docs/api.md).
Host constructors belong to the runtime. Reactive helpers belong to core.

To change Compose itself, follow [AGENTS](https://github.com/voidmeld/compose/blob/df13c632df6e021ec7258199c1896b2d7e8421d0/AGENTS.md).
