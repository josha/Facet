# Ownership and structure

- [Ownership](https://github.com/voidmeld/compose/blob/2c8a89896db550326fd4c927479ac1672305bb0d/docs/ownership.md): node custody, disposal and failed-build cleanup.
- [Reactivity](https://github.com/voidmeld/compose/blob/2c8a89896db550326fd4c927479ac1672305bb0d/docs/reactive.md): dependency tracking and scheduling.
- [Structural API](https://github.com/voidmeld/compose/blob/2c8a89896db550326fd4c927479ac1672305bb0d/docs/api.md#structure): conditional branches and collections.

Choose the resource owner before you build the scene. Components return composition. The root controls their lifetime.
