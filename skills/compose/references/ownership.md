# Ownership and structure

- [Ownership](https://github.com/voidmeld/compose/blob/1a7930a4977360c1df2849b64c6e267895a5a8ad/docs/ownership.md): node custody, disposal and failed-build cleanup.
- [Reactivity](https://github.com/voidmeld/compose/blob/1a7930a4977360c1df2849b64c6e267895a5a8ad/docs/reactive.md): dependency tracking and scheduling.
- [Structural API](https://github.com/voidmeld/compose/blob/1a7930a4977360c1df2849b64c6e267895a5a8ad/docs/api.md#structure): conditional branches and collections.

Choose the resource owner before you build the scene. Components return composition. The root controls their lifetime.
