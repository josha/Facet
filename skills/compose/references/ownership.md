# Ownership and structure

- [Ownership](https://github.com/voidmeld/compose/blob/ed40b1034d0cb14cdf442e1f6129ea6cb12bcc52/docs/ownership.md): node custody, disposal and failed-build cleanup.
- [Reactivity](https://github.com/voidmeld/compose/blob/ed40b1034d0cb14cdf442e1f6129ea6cb12bcc52/docs/reactive.md): dependency tracking and scheduling.
- [Structural API](https://github.com/voidmeld/compose/blob/ed40b1034d0cb14cdf442e1f6129ea6cb12bcc52/docs/api.md#structure): conditional branches and collections.

Choose the resource owner before you build the scene. Components return composition. The root controls their lifetime.
