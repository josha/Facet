# Ownership and structure

- [Ownership](https://github.com/voidmeld/compose/blob/36acaafa0f600f012656f1bf38182cf22c14e728/docs/ownership.md): node custody, disposal and failed-build cleanup.
- [Reactivity](https://github.com/voidmeld/compose/blob/36acaafa0f600f012656f1bf38182cf22c14e728/docs/reactive.md): dependency tracking and scheduling.
- [Structural API](https://github.com/voidmeld/compose/blob/36acaafa0f600f012656f1bf38182cf22c14e728/docs/api.md#structure): conditional branches and collections.

Choose the resource owner before you build the scene. Components return composition. The root controls their lifetime.
