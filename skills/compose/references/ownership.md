# Ownership and structure

- [Ownership](https://github.com/voidmeld/compose/blob/885b11f52972c9153bd40bb6b7b64ef7a264a7ee/docs/ownership.md): node custody, disposal and failed-build cleanup.
- [Reactivity](https://github.com/voidmeld/compose/blob/885b11f52972c9153bd40bb6b7b64ef7a264a7ee/docs/reactive.md): dependency tracking and scheduling.
- [Structural API](https://github.com/voidmeld/compose/blob/885b11f52972c9153bd40bb6b7b64ef7a264a7ee/docs/api.md#structure): conditional branches and collections.

Choose the resource owner before you build the scene. Components return composition. The root controls their lifetime.
