# Ownership and structure

- [Ownership](https://github.com/voidmeld/compose/blob/0e0d939871fb7cb528f6ce0ac4917662424d1708/docs/ownership.md): node custody, disposal and failed-build cleanup.
- [Reactivity](https://github.com/voidmeld/compose/blob/0e0d939871fb7cb528f6ce0ac4917662424d1708/docs/reactive.md): dependency tracking and scheduling.
- [Structural API](https://github.com/voidmeld/compose/blob/0e0d939871fb7cb528f6ce0ac4917662424d1708/docs/api.md#structure): conditional branches and collections.

Choose the resource owner before you build the scene. Components return composition. The root controls their lifetime.
