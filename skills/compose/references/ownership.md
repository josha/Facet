# Ownership and structure

- [Ownership](https://github.com/voidmeld/compose/blob/ae9bc66c686606a3d6e20932b93b1c9a68f9f8d5/docs/ownership.md): node custody, disposal and failed-build cleanup.
- [Reactivity](https://github.com/voidmeld/compose/blob/ae9bc66c686606a3d6e20932b93b1c9a68f9f8d5/docs/reactive.md): dependency tracking and scheduling.
- [Structural API](https://github.com/voidmeld/compose/blob/ae9bc66c686606a3d6e20932b93b1c9a68f9f8d5/docs/api.md#structure): conditional branches and collections.

Choose the resource owner before you build the scene. Components return composition. The root controls their lifetime.
