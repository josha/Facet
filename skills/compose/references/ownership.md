# Ownership and structure

- [Ownership](https://github.com/voidmeld/compose/blob/8b8f10f67b10bccf2e19c43a0321c21cf9183e96/docs/ownership.md): node custody, disposal and failed-build cleanup.
- [Reactivity](https://github.com/voidmeld/compose/blob/8b8f10f67b10bccf2e19c43a0321c21cf9183e96/docs/reactive.md): dependency tracking and scheduling.
- [Structural API](https://github.com/voidmeld/compose/blob/8b8f10f67b10bccf2e19c43a0321c21cf9183e96/docs/api.md#structure): conditional branches and collections.

Choose the resource owner before you build the scene. Components return composition. The root controls their lifetime.
