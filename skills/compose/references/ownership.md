# Ownership and structure

- [Ownership](https://github.com/voidmeld/compose/blob/514a3bd6ec89ed215f55e651fe6b8c11cbeb5175/docs/ownership.md): node custody, disposal and failed-build cleanup.
- [Reactivity](https://github.com/voidmeld/compose/blob/514a3bd6ec89ed215f55e651fe6b8c11cbeb5175/docs/reactive.md): dependency tracking and scheduling.
- [Structural API](https://github.com/voidmeld/compose/blob/514a3bd6ec89ed215f55e651fe6b8c11cbeb5175/docs/api.md#structure): conditional branches and collections.

Choose the resource owner before you build the scene. Components return composition. The root controls their lifetime.
