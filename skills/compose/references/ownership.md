# Ownership and structure

- [Ownership](https://github.com/voidmeld/compose/blob/95bb81aac2f21be1d79a3be1458aac98d93d45ef/docs/ownership.md): node custody, disposal and failed-build cleanup.
- [Reactivity](https://github.com/voidmeld/compose/blob/95bb81aac2f21be1d79a3be1458aac98d93d45ef/docs/reactive.md): dependency tracking and scheduling.
- [Structural API](https://github.com/voidmeld/compose/blob/95bb81aac2f21be1d79a3be1458aac98d93d45ef/docs/api.md#structure): conditional branches and collections.

Choose the resource owner before you build the scene. Components return composition. The root controls their lifetime.
