# Ownership and structure

- [Ownership](https://github.com/voidmeld/compose/blob/f2225ecf1b04a3b161bd17f1082551bffee13c84/docs/ownership.md): node custody, disposal and failed-build cleanup.
- [Reactivity](https://github.com/voidmeld/compose/blob/f2225ecf1b04a3b161bd17f1082551bffee13c84/docs/reactive.md): dependency tracking and scheduling.
- [Structural API](https://github.com/voidmeld/compose/blob/f2225ecf1b04a3b161bd17f1082551bffee13c84/docs/api.md#structure): conditional branches and collections.

Choose the resource owner before you build the scene. Components return composition. The root controls their lifetime.
