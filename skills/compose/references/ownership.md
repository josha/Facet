# Ownership and structure

- [Ownership](https://github.com/voidmeld/compose/blob/d74f653e67baf9b22872a8161a0e010c4db7c750/docs/ownership.md): node custody, disposal and failed-build cleanup.
- [Reactivity](https://github.com/voidmeld/compose/blob/d74f653e67baf9b22872a8161a0e010c4db7c750/docs/reactive.md): dependency tracking and scheduling.
- [Structural API](https://github.com/voidmeld/compose/blob/d74f653e67baf9b22872a8161a0e010c4db7c750/docs/api.md#structure): conditional branches and collections.

Choose the resource owner before you build the scene. Components return composition. The root controls their lifetime.
