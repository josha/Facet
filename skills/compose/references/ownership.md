# Ownership and structure

- [Ownership](https://github.com/voidmeld/compose/blob/1836eaaa4da1e39046d9a3176be768890cf50731/docs/ownership.md): node custody, disposal and failed-build cleanup.
- [Reactivity](https://github.com/voidmeld/compose/blob/1836eaaa4da1e39046d9a3176be768890cf50731/docs/reactive.md): dependency tracking and scheduling.
- [Structural API](https://github.com/voidmeld/compose/blob/1836eaaa4da1e39046d9a3176be768890cf50731/docs/api.md#structure): conditional branches and collections.

Choose the resource owner before you build the scene. Components return composition. The root controls their lifetime.
