# Ownership and structure

- [Ownership](https://github.com/voidmeld/compose/blob/2d03ca1f097bc99efacefa5da74c51fea3ab78e7/docs/ownership.md): node custody, disposal and failed-build cleanup.
- [Reactivity](https://github.com/voidmeld/compose/blob/2d03ca1f097bc99efacefa5da74c51fea3ab78e7/docs/reactive.md): dependency tracking and scheduling.
- [Structural API](https://github.com/voidmeld/compose/blob/2d03ca1f097bc99efacefa5da74c51fea3ab78e7/docs/api.md#structure): conditional branches and collections.

Choose the resource owner before you build the scene. Components return composition. The root controls their lifetime.
