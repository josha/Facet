# Ownership and structure

- [Ownership](https://github.com/voidmeld/compose/blob/2bfff237653f55eddfc353513ac527595acd93a0/docs/ownership.md): node custody, disposal and failed-build cleanup.
- [Reactivity](https://github.com/voidmeld/compose/blob/2bfff237653f55eddfc353513ac527595acd93a0/docs/reactive.md): dependency tracking and scheduling.
- [Structural API](https://github.com/voidmeld/compose/blob/2bfff237653f55eddfc353513ac527595acd93a0/docs/api.md#structure): conditional branches and collections.

Choose the resource owner before you build the scene. Components return composition. The root controls their lifetime.
