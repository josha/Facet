# Ownership and structure

- [Ownership](https://github.com/voidmeld/compose/blob/d6592f915cc32e109c79d66f673c100afd146968/docs/ownership.md): node custody, disposal and failed-build cleanup.
- [Reactivity](https://github.com/voidmeld/compose/blob/d6592f915cc32e109c79d66f673c100afd146968/docs/reactive.md): dependency tracking and scheduling.
- [Structural API](https://github.com/voidmeld/compose/blob/d6592f915cc32e109c79d66f673c100afd146968/docs/api.md#structure): conditional branches and collections.

Choose the resource owner before you build the scene. Components return composition. The root controls their lifetime.
