# Ownership and structure

- [Ownership](https://github.com/voidmeld/compose/blob/e50a4096518be8328d412e240e5abe6f64f6e89f/docs/ownership.md): node custody, disposal and failed-build cleanup.
- [Reactivity](https://github.com/voidmeld/compose/blob/e50a4096518be8328d412e240e5abe6f64f6e89f/docs/reactive.md): dependency tracking and scheduling.
- [Structural API](https://github.com/voidmeld/compose/blob/e50a4096518be8328d412e240e5abe6f64f6e89f/docs/api.md#structure): conditional branches and collections.

Choose the resource owner before you build the scene. Components return composition. The root controls their lifetime.
