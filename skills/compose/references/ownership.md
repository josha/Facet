# Ownership and structure

- [Ownership](https://github.com/voidmeld/compose/blob/249a31dc1a2895ebe99ae56667b43c3064129a39/docs/ownership.md): node custody, disposal and failed-build cleanup.
- [Reactivity](https://github.com/voidmeld/compose/blob/249a31dc1a2895ebe99ae56667b43c3064129a39/docs/reactive.md): dependency tracking and scheduling.
- [Structural API](https://github.com/voidmeld/compose/blob/249a31dc1a2895ebe99ae56667b43c3064129a39/docs/api.md#structure): conditional branches and collections.

Choose the resource owner before you build the scene. Components return composition. The root controls their lifetime.
