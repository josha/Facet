# Ownership and structure

- [Ownership](https://github.com/voidmeld/compose/blob/df13c632df6e021ec7258199c1896b2d7e8421d0/docs/ownership.md): node custody, disposal and failed-build cleanup.
- [Reactivity](https://github.com/voidmeld/compose/blob/df13c632df6e021ec7258199c1896b2d7e8421d0/docs/reactive.md): dependency tracking and scheduling.
- [Structural API](https://github.com/voidmeld/compose/blob/df13c632df6e021ec7258199c1896b2d7e8421d0/docs/api.md#structure): conditional branches and collections.

Choose the resource owner before you build the scene. Components return composition. The root controls their lifetime.
