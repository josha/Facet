# Ownership and structure

- [Ownership](https://github.com/voidmeld/compose/blob/c872f38ad12a73087175caccd3025d2fc9e18393/docs/ownership.md): node custody, disposal and failed-build cleanup.
- [Reactivity](https://github.com/voidmeld/compose/blob/c872f38ad12a73087175caccd3025d2fc9e18393/docs/reactive.md): dependency tracking and scheduling.
- [Structural API](https://github.com/voidmeld/compose/blob/c872f38ad12a73087175caccd3025d2fc9e18393/docs/api.md#structure): conditional branches and collections.

Choose the resource owner before you build the scene. Components return composition. The root controls their lifetime.
