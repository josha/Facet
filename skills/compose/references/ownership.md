# Ownership and structure

- [Ownership](https://github.com/voidmeld/compose/blob/c8164df93ef222734030d8b5ca2c62f3868740ab/docs/ownership.md): node custody, disposal and failed-build cleanup.
- [Reactivity](https://github.com/voidmeld/compose/blob/c8164df93ef222734030d8b5ca2c62f3868740ab/docs/reactive.md): dependency tracking and scheduling.
- [Structural API](https://github.com/voidmeld/compose/blob/c8164df93ef222734030d8b5ca2c62f3868740ab/docs/api.md#structure): conditional branches and collections.

Choose the resource owner before you build the scene. Components return composition. The root controls their lifetime.
