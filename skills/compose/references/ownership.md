# Ownership and structure

- [Ownership](https://github.com/voidmeld/compose/blob/45e11085bb526211180a5d437c5e78a9c1a53084/docs/ownership.md): node custody, disposal and failed-build cleanup.
- [Reactivity](https://github.com/voidmeld/compose/blob/45e11085bb526211180a5d437c5e78a9c1a53084/docs/reactive.md): dependency tracking and scheduling.
- [Structural API](https://github.com/voidmeld/compose/blob/45e11085bb526211180a5d437c5e78a9c1a53084/docs/api.md#structure): conditional branches and collections.

Choose the resource owner before you build the scene. Components return composition. The root controls their lifetime.
