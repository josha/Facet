# Ownership and structure

- [Ownership](https://github.com/voidmeld/compose/blob/49668e8cb27d5e2b273be8fe057145a44ffde562/docs/ownership.md): node custody, disposal and failed-build cleanup.
- [Reactivity](https://github.com/voidmeld/compose/blob/49668e8cb27d5e2b273be8fe057145a44ffde562/docs/reactive.md): dependency tracking and scheduling.
- [Structural API](https://github.com/voidmeld/compose/blob/49668e8cb27d5e2b273be8fe057145a44ffde562/docs/api.md#structure): conditional branches and collections.

Choose the resource owner before building the scene. Components return composition; the root
controls their lifetime.
