# Ownership and structure

- [Ownership](https://github.com/voidmeld/compose/blob/a526574b18c51810dc9c99ded26235cdea9a9c5b/docs/ownership.md): node custody, disposal and failed-build cleanup.
- [Reactivity](https://github.com/voidmeld/compose/blob/a526574b18c51810dc9c99ded26235cdea9a9c5b/docs/reactive.md): dependency tracking and scheduling.
- [Structural API](https://github.com/voidmeld/compose/blob/a526574b18c51810dc9c99ded26235cdea9a9c5b/docs/api.md#structure): conditional branches and collections.

Choose the resource owner before you build the scene. Components return composition. The root controls their lifetime.
