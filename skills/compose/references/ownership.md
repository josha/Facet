# Ownership and structure

- [Ownership](https://github.com/voidmeld/compose/blob/0b2af86b4d5c07321c6bf31b5b35fe5ff73ab0d4/docs/ownership.md): node custody, disposal and failed-build cleanup.
- [Reactivity](https://github.com/voidmeld/compose/blob/0b2af86b4d5c07321c6bf31b5b35fe5ff73ab0d4/docs/reactive.md): dependency tracking and scheduling.
- [Structural API](https://github.com/voidmeld/compose/blob/0b2af86b4d5c07321c6bf31b5b35fe5ff73ab0d4/docs/api.md#structure): conditional branches and collections.

Choose the resource owner before you build the scene. Components return composition. The root controls their lifetime.
