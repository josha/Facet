# Ownership and structure

- [Ownership](https://github.com/voidmeld/compose/blob/0e3ca078f5052b1bc2cfef879ffd40f8850de6b9/docs/ownership.md): node custody, disposal and failed-build cleanup.
- [Reactivity](https://github.com/voidmeld/compose/blob/0e3ca078f5052b1bc2cfef879ffd40f8850de6b9/docs/reactive.md): dependency tracking and scheduling.
- [Structural API](https://github.com/voidmeld/compose/blob/0e3ca078f5052b1bc2cfef879ffd40f8850de6b9/docs/api.md#structure): conditional branches and collections.

Choose the resource owner before you build the scene. Components return composition. The root controls their lifetime.
