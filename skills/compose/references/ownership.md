# Ownership and structure

- [Ownership](https://github.com/voidmeld/compose/blob/79f32d61c4c6dd15e76efb01681ba308d55c52c6/docs/ownership.md): node custody, disposal and failed-build cleanup.
- [Reactivity](https://github.com/voidmeld/compose/blob/79f32d61c4c6dd15e76efb01681ba308d55c52c6/docs/reactive.md): dependency tracking and scheduling.
- [Structural API](https://github.com/voidmeld/compose/blob/79f32d61c4c6dd15e76efb01681ba308d55c52c6/docs/api.md#structure): conditional branches and collections.

Choose the resource owner before you build the scene. Components return composition. The root controls their lifetime.
