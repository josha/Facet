# Ownership and structure

- [Ownership](https://github.com/voidmeld/compose/blob/713ba9226e2157a0365ab52a209292fc53d4ae9c/docs/ownership.md): node custody, disposal and failed-build cleanup.
- [Reactivity](https://github.com/voidmeld/compose/blob/713ba9226e2157a0365ab52a209292fc53d4ae9c/docs/reactive.md): dependency tracking and scheduling.
- [Structural API](https://github.com/voidmeld/compose/blob/713ba9226e2157a0365ab52a209292fc53d4ae9c/docs/api.md#structure): conditional branches and collections.

Choose the resource owner before you build the scene. Components return composition. The root controls their lifetime.
