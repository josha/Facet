# Ownership and structure

- [Ownership](https://github.com/voidmeld/compose/blob/0624ea75a92602f191a2c82009533fee5d81d80f/docs/ownership.md): node custody, disposal and failed-build cleanup.
- [Reactivity](https://github.com/voidmeld/compose/blob/0624ea75a92602f191a2c82009533fee5d81d80f/docs/reactive.md): dependency tracking and scheduling.
- [Structural API](https://github.com/voidmeld/compose/blob/0624ea75a92602f191a2c82009533fee5d81d80f/docs/api.md#structure): conditional branches and collections.

Choose the resource owner before you build the scene. Components return composition. The root controls their lifetime.
