# Ownership and structure

- [Ownership](https://github.com/voidmeld/compose/blob/0e4848e793a2caede121d6dad0b21ecba8185c04/docs/ownership.md): node custody, disposal and failed-build cleanup.
- [Reactivity](https://github.com/voidmeld/compose/blob/0e4848e793a2caede121d6dad0b21ecba8185c04/docs/reactive.md): dependency tracking and scheduling.
- [Structural API](https://github.com/voidmeld/compose/blob/0e4848e793a2caede121d6dad0b21ecba8185c04/docs/api.md#structure): conditional branches and collections.

Choose the resource owner before you build the scene. Components return composition. The root controls their lifetime.
