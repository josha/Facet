# Ownership and structure

- [Ownership](https://github.com/voidmeld/compose/blob/8a1ed67ea6ae71807a2c00cf7bc6f35d4479b472/docs/ownership.md): node custody, disposal and failed-build cleanup.
- [Reactivity](https://github.com/voidmeld/compose/blob/8a1ed67ea6ae71807a2c00cf7bc6f35d4479b472/docs/reactive.md): dependency tracking and scheduling.
- [Structural API](https://github.com/voidmeld/compose/blob/8a1ed67ea6ae71807a2c00cf7bc6f35d4479b472/docs/api.md#structure): conditional branches and collections.

Choose the resource owner before you build the scene. Components return composition. The root controls their lifetime.
