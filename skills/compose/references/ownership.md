# Ownership and structure

- [Ownership](https://github.com/voidmeld/compose/blob/1667ae2fb154994a88b0ecbbc5e5cfb95cb23003/docs/ownership.md): node custody, disposal and failed-build cleanup.
- [Reactivity](https://github.com/voidmeld/compose/blob/1667ae2fb154994a88b0ecbbc5e5cfb95cb23003/docs/reactive.md): dependency tracking and scheduling.
- [Structural API](https://github.com/voidmeld/compose/blob/1667ae2fb154994a88b0ecbbc5e5cfb95cb23003/docs/api.md#structure): conditional branches and collections.

Choose the resource owner before you build the scene. Components return composition. The root controls their lifetime.
