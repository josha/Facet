# Ownership and structure

- [Ownership](https://github.com/voidmeld/compose/blob/185bc974fc2ba6b153fd6af047419fe7687ebad4/docs/ownership.md): node custody, disposal and failed-build cleanup.
- [Reactivity](https://github.com/voidmeld/compose/blob/185bc974fc2ba6b153fd6af047419fe7687ebad4/docs/reactive.md): dependency tracking and scheduling.
- [Structural API](https://github.com/voidmeld/compose/blob/185bc974fc2ba6b153fd6af047419fe7687ebad4/docs/api.md#structure): conditional branches and collections.

Choose the resource owner before you build the scene. Components return composition. The root controls their lifetime.
