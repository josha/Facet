# Ownership and structure

- [Ownership](https://github.com/voidmeld/compose/blob/a2776091d4a4d27268ea3ec6a40a8eed87275412/docs/ownership.md): node custody, disposal and failed-build cleanup.
- [Reactivity](https://github.com/voidmeld/compose/blob/a2776091d4a4d27268ea3ec6a40a8eed87275412/docs/reactive.md): dependency tracking and scheduling.
- [Structural API](https://github.com/voidmeld/compose/blob/a2776091d4a4d27268ea3ec6a40a8eed87275412/docs/api.md#structure): conditional branches and collections.

Choose the resource owner before you build the scene. Components return composition. The root controls their lifetime.
