# Ownership and structure

- [Ownership](https://github.com/voidmeld/compose/blob/b1c92f3165d88d62b6a196a2eaa548bb4e98689f/docs/ownership.md): node custody, disposal and failed-build cleanup.
- [Reactivity](https://github.com/voidmeld/compose/blob/b1c92f3165d88d62b6a196a2eaa548bb4e98689f/docs/reactive.md): dependency tracking and scheduling.
- [Structural API](https://github.com/voidmeld/compose/blob/b1c92f3165d88d62b6a196a2eaa548bb4e98689f/docs/api.md#structure): conditional branches and collections.

Choose the resource owner before you build the scene. Components return composition. The root controls their lifetime.
