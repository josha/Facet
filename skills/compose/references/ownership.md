# Ownership and structure

- [Ownership](https://github.com/voidmeld/compose/blob/9c6f1e0b8961d29cb6234e1e798ae152bfaa05f9/docs/ownership.md): node custody, disposal and failed-build cleanup.
- [Reactivity](https://github.com/voidmeld/compose/blob/9c6f1e0b8961d29cb6234e1e798ae152bfaa05f9/docs/reactive.md): dependency tracking and scheduling.
- [Structural API](https://github.com/voidmeld/compose/blob/9c6f1e0b8961d29cb6234e1e798ae152bfaa05f9/docs/api.md#structure): conditional branches and collections.

Choose the resource owner before you build the scene. Components return composition. The root controls their lifetime.
