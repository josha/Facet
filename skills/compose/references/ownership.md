# Ownership and structure

- [Ownership](https://github.com/voidmeld/compose/blob/e3bfb56c21e4b1a284e6e918edcd0ac364d1e569/docs/ownership.md): node custody, disposal and failed-build cleanup.
- [Reactivity](https://github.com/voidmeld/compose/blob/e3bfb56c21e4b1a284e6e918edcd0ac364d1e569/docs/reactive.md): dependency tracking and scheduling.
- [Structural API](https://github.com/voidmeld/compose/blob/e3bfb56c21e4b1a284e6e918edcd0ac364d1e569/docs/api.md#structure): conditional branches and collections.

Choose the resource owner before you build the scene. Components return composition. The root controls their lifetime.
