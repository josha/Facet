# Ownership and structure

- [Ownership](https://github.com/voidmeld/compose/blob/ad5fe3a8d8d34c092c0f2b3ba2857b4856df069d/docs/ownership.md): node custody, disposal and failed-build cleanup.
- [Reactivity](https://github.com/voidmeld/compose/blob/ad5fe3a8d8d34c092c0f2b3ba2857b4856df069d/docs/reactive.md): dependency tracking and scheduling.
- [Structural API](https://github.com/voidmeld/compose/blob/ad5fe3a8d8d34c092c0f2b3ba2857b4856df069d/docs/api.md#structure): conditional branches and collections.

Choose the resource owner before you build the scene. Components return composition. The root controls their lifetime.
