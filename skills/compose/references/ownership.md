# Ownership and structure

- [Ownership](https://github.com/voidmeld/compose/blob/8cd36561bb04f4124d957750929abea9e4fb7c25/docs/ownership.md): node custody, disposal and failed-build cleanup.
- [Reactivity](https://github.com/voidmeld/compose/blob/8cd36561bb04f4124d957750929abea9e4fb7c25/docs/reactive.md): dependency tracking and scheduling.
- [Structural API](https://github.com/voidmeld/compose/blob/8cd36561bb04f4124d957750929abea9e4fb7c25/docs/api.md#structure): conditional branches and collections.

Choose the resource owner before you build the scene. Components return composition. The root controls their lifetime.
