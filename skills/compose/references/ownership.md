# Ownership and structure

- [Ownership](https://github.com/voidmeld/compose/blob/27471e08cd986812bec8153928576e2f2532a061/docs/ownership.md): node custody, disposal and failed-build cleanup.
- [Reactivity](https://github.com/voidmeld/compose/blob/27471e08cd986812bec8153928576e2f2532a061/docs/reactive.md): dependency tracking and scheduling.
- [Structural API](https://github.com/voidmeld/compose/blob/27471e08cd986812bec8153928576e2f2532a061/docs/api.md#structure): conditional branches and collections.

Choose the resource owner before you build the scene. Components return composition. The root controls their lifetime.
