# Ownership and structure

- [Ownership](https://github.com/voidmeld/compose/blob/f84dcb909efac0c54bfb349b1276be5b26c9cb50/docs/ownership.md): node custody, disposal and failed-build cleanup.
- [Reactivity](https://github.com/voidmeld/compose/blob/f84dcb909efac0c54bfb349b1276be5b26c9cb50/docs/reactive.md): dependency tracking and scheduling.
- [Structural API](https://github.com/voidmeld/compose/blob/f84dcb909efac0c54bfb349b1276be5b26c9cb50/docs/api.md#structure): conditional branches and collections.

Choose the resource owner before you build the scene. Components return composition. The root controls their lifetime.
