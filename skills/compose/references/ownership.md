# Ownership and structure

- [Ownership](https://github.com/voidmeld/compose/blob/9d7a963f1e8c58b5e5327fb9801872c2613a2ce1/docs/ownership.md): node custody, disposal and failed-build cleanup.
- [Reactivity](https://github.com/voidmeld/compose/blob/9d7a963f1e8c58b5e5327fb9801872c2613a2ce1/docs/reactive.md): dependency tracking and scheduling.

Choose the resource owner before you build the scene. Components return composition. The root controls their lifetime.
