# Ownership and structure

- [Ownership](https://github.com/voidmeld/compose/blob/60b9241d66a8b5611a01cec50893f70419341e1b/docs/ownership.md): node custody, disposal and failed-build cleanup.
- [Reactivity](https://github.com/voidmeld/compose/blob/60b9241d66a8b5611a01cec50893f70419341e1b/docs/reactive.md): dependency tracking and scheduling.
- [Structural API](https://github.com/voidmeld/compose/blob/60b9241d66a8b5611a01cec50893f70419341e1b/docs/api.md#structure): conditional branches and collections.

Choose the resource owner before building the scene. Components return composition; the root
controls their lifetime.
