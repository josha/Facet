# Ownership and structure

- [Ownership](https://github.com/voidmeld/compose/blob/1615759a6778ef194b0e14365c34cee4c9ffacf8/docs/ownership.md): node custody, disposal and failed-build cleanup.
- [Reactivity](https://github.com/voidmeld/compose/blob/1615759a6778ef194b0e14365c34cee4c9ffacf8/docs/reactive.md): dependency tracking and scheduling.
- [Structural API](https://github.com/voidmeld/compose/blob/1615759a6778ef194b0e14365c34cee4c9ffacf8/docs/api.md#structure): conditional branches and collections.

Choose the resource owner before you build the scene. Components return composition. The root controls their lifetime.
