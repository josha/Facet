# Ownership and structure

- [Ownership](https://github.com/voidmeld/compose/blob/95677df5b4f09dfec34b643dbda96de189abbc7b/docs/ownership.md): node custody, disposal and failed-build cleanup.
- [Reactivity](https://github.com/voidmeld/compose/blob/95677df5b4f09dfec34b643dbda96de189abbc7b/docs/reactive.md): dependency tracking and scheduling.
- [Structural API](https://github.com/voidmeld/compose/blob/95677df5b4f09dfec34b643dbda96de189abbc7b/docs/api.md#structure): conditional branches and collections.

Choose the resource owner before you build the scene. Components return composition. The root controls their lifetime.
