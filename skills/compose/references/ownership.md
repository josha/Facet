# Ownership and structure

- [Ownership](https://github.com/voidmeld/compose/blob/ee44a2e5499f81790a0d495d3442f99e573bb8c9/docs/ownership.md): node custody, disposal and failed-build cleanup.
- [Reactivity](https://github.com/voidmeld/compose/blob/ee44a2e5499f81790a0d495d3442f99e573bb8c9/docs/reactive.md): dependency tracking and scheduling.

Choose the resource owner before you build the scene. Components return composition. The root controls their lifetime.
