# Ownership and structure

- [Ownership](https://github.com/voidmeld/compose/blob/9431565dd789177c0b6c1acdea76b3315fc99ede/docs/ownership.md): node custody, disposal and failed-build cleanup.
- [Reactivity](https://github.com/voidmeld/compose/blob/9431565dd789177c0b6c1acdea76b3315fc99ede/docs/reactive.md): dependency tracking and scheduling.
- [Structural API](https://github.com/voidmeld/compose/blob/9431565dd789177c0b6c1acdea76b3315fc99ede/docs/api.md#structure): conditional branches and collections.

Choose the resource owner before you build the scene. Components return composition. The root controls their lifetime.
