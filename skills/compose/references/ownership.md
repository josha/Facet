# Ownership and structure

- [Ownership](https://github.com/voidmeld/compose/blob/e3c942cb1490f8b7bfc1af59e40cb20d447cd233/docs/ownership.md): node custody, disposal and failed-build cleanup.
- [Reactivity](https://github.com/voidmeld/compose/blob/e3c942cb1490f8b7bfc1af59e40cb20d447cd233/docs/reactive.md): dependency tracking and scheduling.
- [Structural API](https://github.com/voidmeld/compose/blob/e3c942cb1490f8b7bfc1af59e40cb20d447cd233/docs/api.md#structure): conditional branches and collections.

Choose the resource owner before you build the scene. Components return composition. The root controls their lifetime.
